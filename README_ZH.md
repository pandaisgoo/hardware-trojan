# 硬體安全專案：檔案整理與驗證

本包有兩個獨立的資料夾，分別作為 GitHub 倉庫根目錄；不要把它們放進遊戲或 ECG 倉庫裡。

1. netlist-trojan-detector：未修改的提交程式、原建置與執行腳本、新增的評估工具，以及 270 筆公開案例的重新執行結果。
2. aes-trojan-simulation：15 個未修改的 RTL、檔案清單及重現缺件說明；尚無 testbench/Makefile，未重新模擬。

本次沒有改寫兩份對外 PDF，也沒有假造波形。這是程式與證據的整理包；接續撰寫報告可直接使用偵測器 results/ 的數字，並清楚標明插入實作的驗證範圍。

兩個來源包的外層重複目錄已移除；程式檔內容不變。沒有夾帶原始 benchmark、參考答案、編譯二進位檔、字型或不必要的工具安裝檔。
