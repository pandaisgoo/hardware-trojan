# 來源與整理說明

程式來源：使用者上傳 `112021101.zip` 內的 15 個 Verilog 檔案，逐位元組保留。

原始文字／模擬紀錄：使用者提供的 AES 硬體木馬插入實作 PDF。原報告標示 IIS5008 Hardware Security，並說明部分 AES table lookup 已由基礎材料提供。因此本整理版不將全部 AES 核心宣稱為從零獨立撰寫，也不擅自指定上游作者或 LICENSE。

本次只新增目錄說明、檔案清單與 .gitignore。原程式內的參數與註解保留，包含功能使用到的原識別值。

對外報告可以使用專案形式介紹目標、方法與結果；來源資訊仍應保留。公開 RTL、測試材料或波形前，需確認原始模板、第三方元件與相應規範的允許範圍。

本整理環境未執行 RTL 模擬，亦未驗證與 C++ 偵測器的整合。
